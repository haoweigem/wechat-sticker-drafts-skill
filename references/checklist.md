# 贴图号备稿检查表

## 每格动手前

- [ ] 转发在监听（默认本地 127.0.0.1:1080，仅用于公众号后台域名）
- [ ] 公众号会话有效
- [ ] 今天这一格还没做过，不补做错过的格
- [ ] 题材有可核实的来源，不是编的

## 每格存完后

- [ ] 返回成功，拿到草稿 ID
- [ ] 草稿箱总数 +1
- [ ] 贴图类计数 +1，文章类计数不动
- [ ] 新草稿文案、图数、标题都对
- [ ] 测试稿、重复稿、文章稿原样未动
- [ ] 证据记录已写（时间、题材、字数、图数、草稿 ID、前后计数）

## 文案自检

- [ ] 250 字以内（含标点和空格）
- [ ] 一句谁发布了什么，两三句为什么重要，一句提醒，一句来源
- [ ] 没把“开放权重”写成“开源”
- [ ] 没编价格、链接、日期
- [ ] 没有文章体结尾广告

## 图片自检

- [ ] 4 张，9:16 竖图
- [ ] 同一条只有一种风格
- [ ] 图上文字少、无乱码、无大段文字
- [ ] 四张角度各不相同
- [ ] 图文对得上

## 常见故障

| 现象 | 先查什么 | 禁忌 |
| --- | --- | --- |
| 转发没监听 | 停下，等用户重启转发并确认监听 | 不要直连 |
| 会话过期 | 把二维码给用户当场扫 | 不要替用户扫，不要关页面后补扫 |
| 后台参数错误 | 编码方式、必填字段 | 不要反复重存 |
| 计数对不上 | 是否重复保存、类型是否错 | 不要自己删稿 |
| 字数超 / 图少 / 比例错 / 风格混 / 图文乱 | 按自检规则修，修不好跳过本格并说明 | 不要拉伸改尺寸，不要硬凑 |
| 没有合适热点 | 停下或跳过本格 | 不要编一个假热点 |

## 手机端逐条检查（用户做）

- [ ] 4 张图齐了，顺序对
- [ ] 文案全文无乱码、无截断、无错字
- [ ] 风格统一，画面清晰
- [ ] 有问题不发布，告诉 Agent 哪条哪张
- [ ] 发布后到已发表列表确认
