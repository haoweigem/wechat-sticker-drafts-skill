# wechat-sticker-drafts

微信公众号贴图号草稿助手 skill：每小时选一条可核实的 AI 热点，写 250 字内口语化文案，配 4 张统一风格的竖图，存为贴图草稿并核对草稿箱。

## 铁律

- 只备稿，不发布。发布一律由用户在手机上逐条预览后人工点。
- 不自动扫码验证，不删改测试稿、重复稿、文章稿。
- 账号、密码、代理凭证不写入 skill、记忆和文件。

## 使用

把本仓库作为 skill 安装后，对助手说“贴图号备稿”或指定日期与时间格（如“今天 21:00 那格”），即可按 `SKILL.md` 的流程备稿；每格的自检与故障处理见 `references/checklist.md`。

## 文件

- `SKILL.md`：工作流与规则
- `references/checklist.md`：每格检查表与故障处理
